# MilestoneVault live proof — M1 design evidence

This public evidence manifest is the committed design record for the canonical live proof project.

- MilestoneVault is a dependency-aware funded project settlement contract.
- Exact milestone tranches settle from immutable packet criteria and dependency state.
- The packet stores the deliverable definition, required criteria, evidence requirements,
  exact tranche, dependency list, deadline, and bounded repair budget before funding.
- Acceptance is derived from criterion facts; payout amount and recipient are fixed by the
  stored milestone packet.

This document is intentionally a compact evidence manifest. It does not claim that any
particular live transaction has occurred; the live proof report records those observations.
