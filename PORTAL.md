# Portal reviewer notes

MilestoneVault is designed to be reviewed from the proof route first. The reviewer should see:

1. the plan object and dependency map;
2. the frozen criterion packet for a selected milestone;
3. the three settlement outcomes: exact payout, no-payout rejection, and unresolved hold;
4. the accounting equation that prevents a client from reclaiming an earned unpaid tranche.

The frontend does not display fabricated transaction links. Configure `VITE_MILESTONEVAULT_CONTRACT_ADDRESS` only after the deployed source and schema have been verified.
